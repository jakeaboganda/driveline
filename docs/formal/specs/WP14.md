## text

No P12 row may be marked CHECKED. check_grammar builds `Lark(src, start=["scenario_file","module_file"], parser="earley", lexer="dynamic")` (check.py:244) and only parses examples/*.dline. Top-level files are parsed as scenario_file and subdirectory files as module_file. Earley accepts ambiguous and non-LL grammars and resolves ambiguity silently, so check.py tests neither LL(2) nor unambiguity (P12-02). Its lexer accepts more than §12 allows. The dynamic lexer backtracks: QUANTITYLIT's lookahead `(?![A-Za-z0-9_])` lets `3.0m/speed` lex as `3.0m` `/` `speed`, against P12-06. STRINGLIT `"(?:\\.|[^"\\])*"` accepts any escape and raw control characters, against P12-08. `>>` is context-free, so P12-04 is untested. Nothing checks that a module file containing a scenario is rejected (P12-01). The IDENT regex excludes the reserved words on the examples only.
