# WP10 statement spec

**Summary:** I wrote the WP10 statement spec. It adds two new modules, Driveline.SteadyState and Driveline.AxleLoad, and a data model built on VehicleSpec.Tier0/Tier1 and Angles.wrap. There is one theorem for each of the 16 rows: 10 have plain theorems, P08-03 is iff-form with a provisional REFUTE, P06-23 is GAP, P08-01 is DUP of P06-13, and P03-40 is DEFER. The proofs are over ℝ; tools/check.py:430-447 already checks the numeric test vector and that the DST derivatives vanish. I found four spec gaps and one suspected issue. The main one: §8 and §6.2 divide by L, but the spec only makes l_f+l_r approximately equal to L (see VehicleSpec.cg_readings_disagree). So 'axle forces sum to m a_y' and 'F_zf+F_zr = m g cosθ cosφ' are exact only when l_f+l_r = L. I could not run the rule-5 search for REFUTE rows within the 8-call budget, so the orchestrator must run it before accepting them.

open Real
/-- §8 'g = 9.80665 m/s^2' (08:19) -/
def gStd : ℝ := 9.80665
structure Params where
  L : ℝ  -- wheelbase, Tier 0
  lf : ℝ
  lr : ℝ
  m : ℝ
  Caf : ℝ
  Car : ℝ
  hcg : ℝ
  δmax : ℝ
def Params.ofSpec (t0 : VehicleSpec.Tier0) (t1 : VehicleSpec.Tier1) : Params :=
  ⟨t0.wheelbase, t1.cg_dist_front, t1.cg_dist_rear, t1.mass, t1.cornering_stiffness_f, t1.cornering_stiffness_r, t1.cg_height, t0.max_steer_angle⟩
inductive Tier | ks | st | mb deriving DecidableEq
def aY (v r : ℝ) : ℝ := v * r
noncomputable def deltaKS (L v r : ℝ) : ℝ := arctan (L * r / v)
def Fyf (p : Params) (v r : ℝ) : ℝ := p.m * aY v r * p.lr / p.L
def Fyr (p : Params) (v r : ℝ) : ℝ := p.m * aY v r * p.lf / p.L
def alphaF (p : Params) (v r : ℝ) : ℝ := Fyf p v r / p.Caf
def alphaR (p : Params) (v r : ℝ) : ℝ := Fyr p v r / p.Car
noncomputable def vLatRa (p : Params) (v r : ℝ) : ℝ := -v * tan (alphaR p v r)
noncomputable def deltaSS (p : Params) (v r : ℝ) : ℝ := alphaF p v r + arctan ((vLatRa p v r + p.L * r) / v)
noncomputable def betaCG (p : Params) (v r : ℝ) : ℝ := arctan ((vLatRa p v r + p.lr * r) / v)
def Kus (p : Params) : ℝ := p.m / p.L * (p.lr / p.Caf - p.lf / p.Car)
structure SS where
  vLat : ℝ
  delta : ℝ
/-- §8 tier dispatch for v ≠ 0. The v = 0 cases (arctan(L κ0), or the kept front_wheel_angle) are inputs from §6.2 and are not modeled. -/
noncomputable def solve (t : Tier) (p : Params) (v r : ℝ) : SS := by
  classical exact if t = .ks ∨ v < 1 then ⟨0, deltaKS p.L v r⟩ else ⟨vLatRa p v r, deltaSS p v r⟩
def infeasible (p : Params) (μ δ ay : ℝ) : Prop := p.δmax < |δ| ∨ μ * gStd < |ay|
-- §17 DynamicSingleTrack lateral part, linear (unclamped) tires (17:115-116)
noncomputable def dstAlphaF (p : Params) (vx vy r δ : ℝ) : ℝ := δ - arctan ((vy + p.lf * r) / vx)
noncomputable def dstAlphaR (p : Params) (vx vy r : ℝ) : ℝ := -arctan ((vy - p.lr * r) / vx)
noncomputable def dstVyDot (p : Params) (vx vy r δ : ℝ) : ℝ := (p.Caf * dstAlphaF p vx vy r δ + p.Car * dstAlphaR p vx vy r) / p.m - vx * r
noncomputable def dstRDot (p : Params) (Izz vx vy r δ : ℝ) : ℝ := (p.lf * (p.Caf * dstAlphaF p vx vy r δ) - p.lr * (p.Car * dstAlphaR p vx vy r)) / Izz
-- steady circle: body velocity (v, vl), yaw ψ0 + r t
noncomputable def circVel (ψ0 r v vl t : ℝ) : ℝ × ℝ :=
  (v * cos (ψ0 + r * t) - vl * sin (ψ0 + r * t), v * sin (ψ0 + r * t) + vl * cos (ψ0 + r * t))
noncomputable def toBody (ψ : ℝ) (w : ℝ × ℝ) : ℝ × ℝ := (w.1 * cos ψ + w.2 * sin ψ, -w.1 * sin ψ + w.2 * cos ψ)
noncomputable def rearCurv (v vl r : ℝ) : ℝ := r / sqrt (v ^ 2 + vl ^ 2)
-- supporting lemma (no row): for circVel, (x'y'' - y'x'') / ‖(x',y')‖^3 = rearCurv v vl r

-- AxleLoad
noncomputable def Fzf (p : Params) (θ φ : ℝ) : ℝ := p.m * gStd * cos θ * cos φ * p.lr / p.L - p.m * gStd * sin θ * p.hcg / p.L
noncomputable def Fzr (p : Params) (θ φ : ℝ) : ℝ := p.m * gStd * cos θ * cos φ * p.lf / p.L + p.m * gStd * sin θ * p.hcg / p.L
def facesAgainst (ψ ψlane : ℝ) : Prop := π / 2 < |Angles.wrap (ψ - ψlane)|
noncomputable def relGrade (ψ ψlane θ φ : ℝ) : ℝ × ℝ := by
  classical exact if facesAgainst ψ ψlane then (-θ, -φ) else (θ, φ)
/-- wheels[0..3] in header order, assumed FL, FR, RL, RR: check against §9 -/
noncomputable def wheelFz (p : Params) (θ φ : ℝ) (i : Fin 4) : ℝ := if i.val < 2 then Fzf p θ φ / 2 else Fzr p θ φ / 2

## Findings

* G1 (blocking for P08-03 sum, P06-06, P06-23, P08-04): 08:16-18 and 06:75 divide by L. Only approxEq(l_f+l_r, L) holds, and VehicleSpec.cg_readings_disagree shows WF specs where l_f+l_r ≠ L. So the claims 'axle forces sum to m a_y' and that DST is at rest at δ_ss are exact only if L := l_f + l_r in §8/§6.2. Suggested spec fix: define L in §8 as l_f + l_r. Rule-5 search NOT run within budget: grep -n 'wheelbase\|cg_dist' docs/spec/03-*.md docs/spec/16-*.md docs/spec/08-*.md before accepting the P08-03 REFUTE.
* G2 (major, P08-04/P06-23): recovering α_r from v_lat,ra = −v tan α_r needs |α_r| < π/2. Neither §8 nor feasibility (08:19) bounds α_r = m a_y l_f/(L C_αr). Check the §16 ranges.
* G3 (major, P06-23): 17:115 clamps F_yi to ±μ_i max(0, F_zi). The feasibility rule |a_y| ≤ μ g (08:19) uses μ at the reference origin and does not bound the per-axle force once grade reduces F_zf or μ_f < μ. A feasible state can still be clamped, and then it is not balanced.
* G4 (minor, P06-07): sin θ_road > 0 needs an upper bound on θ_road. Cite the §2 pitch range or add one.
* Issue 1 (major, P06-03): with ψ̇_0 = v_0 κ_0 and v_lat,ra ≠ 0 (ST, κ_0 ≠ 0), the rear-axle path curvature is v κ_0/√(v²+v_lat²) ≠ κ_0. So 'the actor follows it' (06:73) is not exact; for the test vector the relative error is about 9e-5, roughly 4.4 cm of radius at R = 500 m. Fix: either say 'approximately', or solve ψ̇_0 = κ_0 √(v_0² + v_lat,ra²) as a fixed point.
